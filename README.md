## 📘 Descripción general del sistema
Este proyecto corresponde a la Actividad Sumativa 1 de la asignatura Desarrollo Orientado a Objetos I. Se trata de un modelo de clases que representan a las personas vinculadas a la organización "Llanquihue Tour", una agencia de turismo ubicada en la comuna de Llanquihue en la región de Los Lagos. El objetivo es crear un sistema estructurado usando los principios de uso de atributos privados, relaciones, encapsulamiento, herencia entre otros para establecer una base sólida para poder en un futuro escalar el producto de forma adecuada.

## 🧱 Estructura general del proyecto

```plaintext
📁 src/main/java/com/llanquihuetour/
├── app/
│   └── Main.java          # Punto de entrada de la aplicación (método main)
└── model/
    ├── Persona.java        # Clase base que representa a una persona con sus atributos generales
    ├── Direccion.java      # Clase que modela la dirección de una persona
    └── Empleado.java       # Subclase de Persona que representa a un empleado de la agencia
```
